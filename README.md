# EscapeGame

## 開啟遊戲

直接雙擊或拖曳 index.html 至Chrome，看到「密室逃脫之在杰難逃」開始頁後，按「開始遊戲」。背景使用杰哥客廳。劇本已隨程式內建，不需要匯入檔案或啟動伺服器。

也可在專案資料夾執行 python -m http.server 8000，以本機網址開啟。

## 操作

- 劇情：左鍵／空白鍵下一句，長按1.5秒後每秒4句，放開停止。
- 解謎：WASD／方向鍵移動，面向物件按空白調查。首次觀星台詞在底部播放，播完仍保留觀星頁面。
- 抱枕後警報與黑暗追捕；被抓可從關燈台詞重試，前面解題進度保留。
- 帶著太陽鑰匙到客廳左上移櫃、開門，再朝外走才逃出。

## 編修劇本（僅製作者需要）
