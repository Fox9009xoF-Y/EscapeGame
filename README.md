# EscapeGame

## 開啟遊戲

### 直接雙擊或拖曳 index.html 至 Chrome

1. 在遊戲畫面按「選擇檔案」。
2. 按住 Ctrl，同時選取專案內的 `story1.txt` 與 `story2.txt`，即可開始。

每次重新開啟或重新整理網頁，都需要重新選取這兩份劇本。修改劇本後重新選取，遊戲會讀取最新內容；不需要修改程式碼。

### 透過本機網址開啟

在專案資料夾啟動 `python -m http.server 8000`，再開啟 [遊戲](http://127.0.0.1:8000/)。此模式會自動讀取兩份劇本；修改文字後重新整理即可更新。

已串接開場劇情、三道謎題、黑暗追捕、鑰匙移櫃開門及結尾。

## 操作

- 劇情：畫面任意位置按左鍵，或按空白鍵，播放下一句；按住1.5秒後每秒播放4句，放開立即停止。暫停等功能按鈕保留原本功能。
- 解謎：WASD或方向鍵移動，面向物件按空白鍵調查；線索視窗可按「關閉」或Esc，提示由右上角開啟。
- 追捕：與床上抱枕互動後觸發警報與黑暗，按「趕快逃！」開始；被抓後可從關燈台詞重新挑戰，前面解題進度保留。
- 逃脫：帶著太陽鑰匙到客廳左上角移開書櫃，調查大門開門，再朝門外走。

設計推定及實作記錄見[GAMEREPORT.md](GAMEREPORT.md)，逐條驗收及限制見[TEST.md](TEST.md)。目標玩家每題3～5分鐘的難度尚未經試玩確認。
